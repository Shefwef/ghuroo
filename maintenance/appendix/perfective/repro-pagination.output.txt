────────────────────────────────────────────────────────────
  Input  : ?page=1&limit=999

  → limit clamped to 100 — protects against unbounded queries

TEST 7 — Before/After response shape for GET /api/tours
────────────────────────────────────────────────────────────
  BEFORE PFM-01 (getAllTours with 38 tours in DB):
    { success: true, data: [...38 tours...] }  ← full collection every request
    Response size with 1000 tours: ~2 MB
    Response size with 10000 tours: ~20 MB

  AFTER PFM-01:
    { success: true, count: 10, page: 1, totalPages: 4, total: 38, data: [...10 tours...] }
    Response size: constant ~20 KB regardless of collection size
    Client paginates using ?page=2, ?page=3, ...
    Client reads 'totalPages' to know how many pages exist
